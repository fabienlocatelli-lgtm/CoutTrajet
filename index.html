ℹ️ Comment ce calcul est fait Par tronçon : conso = courbe(vitesse) + effet pente + effet vent, × effet pluie.
• Vitesse : estimée par OSRM, plafonnée par votre « vitesse max ».
• Pente : altitudes Open-Meteo le long du tracé. ±1 % de pente ≈ ±1,35 L/100km pour 1200 kg (force = m·g·pente ; énergie essence 32,2 MJ/L ; rendement 27 %).
• Vent : surcroît aérodynamique ½·ρ·CdA·(v_rel²−v²) avec le vent projeté sur l'axe du trajet (ex. 25 km/h de face à 90 km/h ≈ +1,8 L/100km).
• Pluie : +5 % (faible) ou +12 % (forte) — routes mouillées, climatisation.
Le résultat détaille la part de chaque effet.

ℹ️ Les formules utilisées Pente : force F = m·g·pente. Litres/100km = m·9,81·pente ÷ (32,2 MJ/L × 27 %). Montée +1 %, 1200 kg ≈ +1,35 L/100km ; descente autant en moins (plancher ≈ 0 : injection coupée).
Vent : surcroît = ½·1,2·CdA·(v_rel²−v²)·v, v_rel = vitesse ± vent axial. 25 km/h de face à 90 ≈ +1,8 L/100km ; vent arrière : économie symétrique.
Pluie : +5 % faible, +12 % forte (modèle : résistance de roulement mouillé + climatisation).
Étalonnage : le tableau de bord mesure la vraie consommation instantanée du calculateur ; un point étalonné remplace toute estimation à cette vitesse.
